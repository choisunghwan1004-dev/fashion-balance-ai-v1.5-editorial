# Fashion Balance AI V1.3 — 바지/겉옷 색상 기준 코디

## 새 기능
- 기준 아이템: 바지(하의) 또는 겉옷(아우터) 선택
- 기준 색상: MySQL에 등록된 해당 카테고리 색상만 자동 표시
- 코디 추천: 선택한 카테고리와 색상이 정확히 일치하는 DB 상품을 반드시 포함
- 나머지 상의·하의·신발·액세서리는 계절·스타일·예산과 옷장 보유 여부로 조합
- 보유 상품의 추가 구매비용은 0원, 쇼핑 상품만 구매금액 계산
- 기존 계절별 코디 사진 2장 유지(실제 상품 매칭 사진은 아님)

## 실행
1. V1.2와 동일한 DB `fashion_balance` 사용. **V1.3 신규 SQL 변경은 필요 없습니다.**
2. `.env.example`을 `.env`로 복사하고 DB 비밀번호 설정
3. `npm install` → `npm start` → `http://localhost:3000`
4. 바지/겉옷 선택 → 색상 선택 → 계절·스타일·예산 설정 → 추천

## API
- GET `/api/outfits/anchor-colors?category=하의` : 해당 카테고리 등록 색상
- POST `/api/outfits/recommend` : 기존 필드 + `anchorCategory` (`하의` 또는 `아우터`)와 `anchorColor` (예: `네이비`)
- 결과가 없으면 빈 배열을 반환. 선택한 색상/카테고리를 다른 색상으로 바꿔서 추천하지 않습니다.

## 한계
- 샘플 DB에 등록되지 않은 색상·계절·스타일 조합은 추천 불가
- V1.3의 색상 조화는 단순 점수 규칙이며 전문가 수준의 색채 분석은 아님
- 사용자 ID 1 고정의 로컬 데모, 인증 미구현: 인터넷 공개 금지
