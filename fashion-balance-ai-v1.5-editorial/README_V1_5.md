# Fashion Balance AI V1.5 — 패션 에디토리얼 화면 / 사진 등록

- 제공된 두 화면의 배치 분위기를 참고해 첫 화면(코디 추천)과 하위 화면(옷장·트렌드·상품등록)을 통일된 아이보리/세이지/베이지 스타일로 변경했습니다.
- 기존 V1.4 추천·계절 샘플·코디 채택·쇼핑 링크는 유지합니다.
- 내 옷장에서 JPG/PNG/WEBP 최대 3MB 사진을 선택하면 미리보기 후 서버의 `public/uploads`에 저장하고 `fashion_items.image_url`에 기록합니다.
- **사진 AI 자동 분류 기능은 아직 없습니다.** 카테고리·색상·계절은 사용자가 직접 입력하며 사진이 없어도 등록됩니다.
- 샘플 사진은 스타일 참고용이고 실제 DB 상품 사진과 1:1 매칭된 이미지는 아닙니다.
- V1.4 DB를 그대로 사용하므로 별도 마이그레이션 SQL은 필요하지 않습니다.
- `.env`를 설정하고 `npm install`, `npm start`, `http://localhost:3000` 접속.
- 공개 서비스 배포 전 로그인·관리자 권한·이미지 재인코딩/악성파일 검증·파일 삭제 및 사용자별 저장공간 제한이 필요합니다. 현재는 로컬 데모입니다.
