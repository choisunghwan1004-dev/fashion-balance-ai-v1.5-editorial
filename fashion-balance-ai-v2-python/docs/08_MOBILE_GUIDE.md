# 휴대폰 실행·홈 화면 아이콘

## 동작 구조

휴대폰에서 앱 화면을 실행할 수 있습니다. React 화면은 Safari/Chrome에서 열리고 Python 서버와 MySQL은 PC 또는 운영 호스트에서 실행합니다. PC를 종료하거나 서버가 꺼지면 자료 조회·저장이 되지 않습니다. 앱 아이콘을 추가해도 이 서버 연결 조건은 같습니다.

## 같은 Wi-Fi에서 시작

1. PC에서 ipconfig를 실행해 사용 중인 Wi-Fi의 IPv4 주소를 확인합니다.
2. .env 설정을 완료한 프로젝트에서 아래 명령을 실행합니다. 주소는 본인 PC 주소로 바꾸세요.

```powershell
.\.venv\Scripts\python.exe mobile_setup.py --url http://192.168.0.10:3000
.\.venv\Scripts\python.exe run.py
```

3. PC도 휴대폰도 위와 같은 주소를 사용합니다. PC에서 http://192.168.0.10:3000/mobile.html을 열어 QR을 표시합니다.
4. 휴대폰 카메라로 QR을 스캔해 가입합니다. 인증 메일 링크는 실제 로그인할 Safari/Chrome에서 여세요.
5. Windows 방화벽은 신뢰하는 사설 네트워크에서 Python 접속을 허용합니다. 공유기 AP 격리·게스트 Wi-Fi는 PC/휴대폰 연결을 막을 수 있습니다.

localhost와 127.0.0.1은 기기 자신을 가리키므로 휴대폰에서 PC에 연결할 수 없습니다. mobile_setup은 이 주소를 거절하고 APP_BASE_URL만 변경하며 DB 비밀번호 등 나머지 .env는 보존합니다. IP가 바뀌면 다시 설정 후 서버를 재시작합니다.

## 아이콘으로 열기

- iPhone: Safari에서 접속 → 공유 → 홈 화면에 추가.
- Android: Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가. 지원하면 모바일 안내 화면에 설치 버튼이 나타납니다.
- 실제 메뉴·설치 가능 여부는 OS/브라우저 버전과 HTTPS 조건에 따라 달라집니다.
- 홈 화면 아이콘·앱 이름·독립 창 설정은 manifest와 PNG 아이콘으로 제공합니다.

실서비스는 HTTPS 도메인을 사용합니다. 일반 HTTP Wi-Fi 주소에서는 웹 화면 사용은 가능하지만 PWA 설치/서비스워커는 제한될 수 있습니다. localhost는 PC 개발 예외로 지원될 수 있으나 휴대폰의 PC 접속 주소로 쓸 수는 없습니다.

## 집 밖에서 사용

인터넷에 연결된 운영 서버에 Python·MySQL·영구 사진 저장소를 배포하고 HTTPS 도메인을 연결해야 합니다. 이 작업에서 실제 공개 도메인/서버는 지정되지 않았으므로 운영 배포가 완료됐다고 표시하지 않습니다. Docker 구성과 절차는 10_DEPLOYMENT.md에 포함했습니다.

## 오프라인·개인 정보

서비스워커는 공개 앱 껍데기와 정적 파일만 보관합니다. /api/와 /uploads/는 캐시하지 않으며 개인 옷장·사진·체형·이력을 오프라인으로 복제하지 않습니다. 오프라인일 때 안내가 나타나고 조회·저장은 다시 연결한 뒤 사용합니다. 로그인 이메일·토큰을 QR이나 캐시에 넣지 않습니다.
