# 공통 개발지침 — PC·휴대폰 필수 지원

1. 화면은 React, 주요 업무·인증·DB 로직은 Python/FastAPI, DB는 기존 MySQL을 기본으로 한다.
2. 모든 신규·수정 기능은 PC와 휴대폰 모두 사용할 수 있어야 한다. 한쪽만 구현한 상태를 완료로 표시하지 않는다.
3. 기존 화면·스타일·입력 상태·샘플/개인 구분·세부 기능을 보존하고 필요한 범위만 변경한다. 원본을 먼저 분석하고 원인과 계획을 설명한다.
4. 화면 폭 320·390·768·1440px를 대표 크기로 확인한다. 메뉴는 작은 화면에서도 접근 가능해야 하며 문서 전체 가로 넘침을 방지한다.
5. 입력 글씨는 휴대폰 확대를 줄일 수 있도록 16px 이상, 주요 터치 영역은 44px 이상을 기본으로 한다. 촬영과 사진 선택을 모두 고려한다.
6. 저장·등록 후 완료 내용을 보여주고 메인으로 돌아가는 동선을 제공한다. 연속 입력이 필요한 사용자는 계속 관리할 수 있도록 한다.
7. 개인 데이터 권한은 서버에서 검사한다. 쿠키 인증·소유권 확인 없이 옷·사진·체형·이력에 접근하게 하지 않는다.
8. 오류·지연·빈 결과·API 미설정 상태도 사용자에게 표시한다. 키·비밀번호·인증 토큰을 로그·공개 파일에 넣지 않는다.
9. 실제 기기·실제 DB·메일·외부 API 결과와 모의 데이터/브라우저 에뮬레이션을 명확히 구분한다. 수행하지 않은 검증을 통과로 쓰지 않는다.
10. 코드 변경에 맞게 README·설치 가이드·SQL/ERD·테스트 결과·변경 이력을 갱신한다.

이 기준은 프로젝트 루트 `AGENTS.md`에도 반영했다. 다른 프로젝트에도 적용하려면 해당 프로젝트의 개발지침에 이 파일의 조건을 포함한다.
