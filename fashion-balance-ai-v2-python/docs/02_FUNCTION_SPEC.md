# 기능정의서

기능은 구현 범위 기준이며 실제 서비스 연결 검증 여부는 TEST_RESULTS와 인수검사표에서 따로 관리합니다.

| ID | 기능 | 입력 | 처리 | 저장 | 권한 | 확인 기준 |
|---|---|---|---|---|---|---|
| F01 | 최소 가입 | 닉네임·이메일 | 형식/요청 제한 검사 후 15분 일회용 인증 메일 | auth_links 해시 저장 | 미인증 | 메일 수신은 실제 SMTP로 별도 확인 |
| F02 | 인증·로그인 | 메일 링크 토큰 | 트랜잭션으로 1회 소비, HttpOnly 쿠키 발급 | users/auth_sessions | 토큰 보유자 | 인증 후 메인·재사용 거절 |
| F03 | 로그인 유지·로그아웃 | 세션 쿠키 | 만료 확인/현재 세션 삭제 | auth_sessions | 본인 | 로그아웃 후 개인 API 401 |
| F04 | 공용 상품 조회 | 조회 | 샘플/쇼핑 상품만 조회 | fashion_items owner NULL | 공용 | 개인 상품 노출 없음 |
| F05 | 옷장 추가·제거 | 상품 ID | 본인 옷장 연결·제거, 개인 상품은 본인 것만 비활성화 | wardrobe_items/fashion_items | 회원 본인 | 다른 회원 상품 등록 차단 |
| F06 | 직접 옷 등록 | 이름·종류·색상·스타일·계절·사진 | 입력 검증 및 옷/옷장 트랜잭션 | fashion_items/wardrobe_items | 회원 본인 | 저장 후 목록·완료 팝업 |
| F07 | 사진 저장·표시 | JPG/PNG/WEBP 최대3MB | 시그니처 검사·비공개 파일·소유권 검사 | private_photos/파일 | 회원 본인 | 다른 회원 404 |
| F08 | 기기 내 색상 추정 | 선택 사진 | 브라우저 캔버스에서 주요 색상 근사 | 자동 저장 없음 | 기기 내 | 추정값 직접 수정 가능 |
| F09 | 선택적 AI 분석 | 사진·유형·전송 동의 | Python에서 외부 AI 요청·허용 선택값 검증 | 사진 분석 결과만 화면 반영 | 회원+동의 | 키 없으면 수동 선택 안내 |
| F10 | 스타일 프로필 | 얼굴형·체형·톤·핏 | 그림/선택 동기화 후 저장 | style_profiles | 회원 본인 | 슬림/보통/통통 선택과 저장 일치 |
| F11 | 코디 추천 | 계절·스타일·예산·범위·기준 옷/색 | 보유품0원·예산·필수4종·액세서리·프로필 반영 | recommendation_history | 회원 본인 | 최대 두 코디, 조건 불충족 빈 결과 |
| F12 | 코디 채택 | 선택 코디 | 선택 강조·금액·보유 수 안내 | 화면 상태만 | 해당 화면 | 채택 DB 저장 없음 안내 |
| F13 | 추천 이력 | 조회 | 본인 최근30회 | recommendation_history | 회원 본인 | 다른 회원 이력 노출 없음 |
| F14 | 사계절 참고 사진 | 계절 | DB 등록 LOOK2개 | seasonal_looks | 공용 | 실제 상품 동일 이미지로 오인하지 않게 안내 |
| F15 | 트렌드 예시 | 조회 | 관리자 입력 예시 점수 조회 | trends | 공용 | 실시간 통계가 아님을 표시 |
| F16 | 관리자 상품 등록 | 상품·분류·가격·URL | 허용 이메일 권한 확인 후 등록 | fashion_items | ADMIN_EMAILS 회원 | 일반 회원403 |
| F17 | 휴대폰 연결 | 서버 주소 | 주소/QR·네트워크·설치 안내 | 환경설정 읽기 | 공용 | localhost 오설정 안내 |
| F18 | 홈 화면 아이콘 | 설치/추가 | manifest·아이콘·지원 브라우저 설치 안내 | 공개 앱 셸 캐시만 | 브라우저 지원 범위 | 개인 API/사진 캐시 금지 |
| F19 | 저장 완료 이동 | 저장 성공 | 완료 팝업→메인 또는 계속 관리 | 화면 상태 | 해당 사용자 | 중복 제출 방지·오류 표시 |
| F20 | 접속 주소 설정 | --url 옵션 | 기존 비밀 설정을 보존하고 APP_BASE_URL만 변경 | .env | PC 운영자 | localhost 거절·재시작 안내 |
