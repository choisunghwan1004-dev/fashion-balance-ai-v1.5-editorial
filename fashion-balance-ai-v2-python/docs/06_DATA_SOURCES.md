# 데이터 출처·검증 구분

| 자료 | 실제 출처 | 용도·상태 |
|---|---|---|
| 분류·색상·스타일 | 기존 database/seed.sql | 고정 선택 항목 |
| 사계절 상품·가격 | 기존 seed 및 seed_v1_4_demo.sql | 가상/학습 샘플. 현재 실제 판매가 검증 없음 |
| 참고 코디 이미지·체형 그림 | 기존 V1.8 ZIP의 public/images | 참고 이미지이며 실제 DB 상품과 동일성 미확인. 기존 파일 보존 |
| 개인 옷·사진 | 본인이 직접 입력·촬영·업로드 | 해당 회원만 접근. 입력 정확성은 사용자 확인 |
| 체형·얼굴형·톤·핏 | 본인 선택 또는 동의 후 AI 제안 | 추정·선호 정보. 의료/건강/외모 우열 판단 아님 |
| 기기 내 색상 | 선택 사진 픽셀 근사 | 배경·조명 영향. 확인 후 저장 |
| AI 제안 | 서버 설정 OpenAI Responses API | 선택 호출, 결과 확인 필요. 실제 호출 검증은 별도 |
| 트렌드 점수 | 관리자 입력 trends | 실시간 패션 조사나 공인 통계가 아님 |
| 쇼핑 링크 | 기존/관리자 상품 URL | 검색/연결용. 재고·가격·구매 가능성 보장 없음 |
| 가입 이메일·세션 | 사용자 이메일 인증 | 토큰 원문 대신 해시 저장, 인증 메일은 SMTP |
| 문서·검사 결과 | 현재 소스·자동 테스트·브라우저 모의 API | 실제 DB/메일/AI/휴대폰 실기기 검증과 구분 |

외부 이미지·실판매 상품 데이터를 새로 자동 수집하지 않았습니다. 원본 이미지의 권리·상업 이용 조건이 필요한 경우 운영자가 원출처를 확인한 뒤 공개해야 합니다. 기존 파일에 없는 출처나 권한을 임의로 만들어 기재하지 않습니다.
