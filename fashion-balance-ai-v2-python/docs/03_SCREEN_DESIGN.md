# 화면설계서

## 화면과 동선

| 화면 | 경로 | 주요 항목 | 입력·조회 후 처리 |
|---|---|---|---|
| 메인 | / | 소개·조건 선택·사계절2사진·추천2코디·금액/소유 표시 | 추천은 버튼 요청, 채택은 선택 강조. 이력은 서버 저장 |
| 옷장 | /wardrobe.html | 공용 상품 선택·내 사진·직접 입력·보유 목록 | 사진 선택/촬영→미리보기→수동/AI 확인→등록→완료 팝업 |
| 스타일 | /profile.html | 얼굴 사진·전신 사진·체형 그림·선택란 | AI는 제안만 반영, 저장 버튼으로 확정→완료 팝업 |
| 트렌드 | /trends.html | 연도·계절·스타일·점수·예시 설명 | 조회, 샘플 점수임을 명시 |
| 관리자 | /admin.html | 상품 분류·계절·가격·URL | 관리자 인증 검사 후 등록→완료 팝업 |
| 가입·로그인 | /login.html | 닉네임·이메일·QR·인증 완료 버튼 | 메일 발송→링크 확인→로그인 완료→메인 |
| 추천 이력 | /history.html | 본인 최근30회·시각·품목·구매합계 | 본인만 조회, 빈 목록 안내 |
| 휴대폰 안내 | /mobile.html | 현재 서버 주소·QR·설치 안내·온라인 조건 | localhost 경고, 기기별 홈 화면 추가 안내 |

## PC와 휴대폰 배치

PC는 기존 상단 메뉴·좌측 소개·콘텐츠 배치를 유지하고 코디 카드는 2열을 사용합니다. 좁은 화면에서는 소개 사이드 영역을 접고 본문·코디·사진·프로필 입력을 1열로 바꿉니다. 메뉴는 내부 가로 스크롤로 접근하며 문서 전체가 가로로 밀리지 않게 구성합니다.
입력 글씨는 16px, 주요 버튼/메뉴 터치 영역은 44px를 기본으로 합니다. 기존 색상·사진·여백 체계를 유지합니다. 체형 그림은 세 가지 기본형과 기존 세부 실루엣 선택을 함께 제공합니다.

## 저장·오류·빈 상태

저장 중 중복 제출을 막고 결과는 메시지/완료 팝업으로 보여줍니다. 성공하면 메인 복귀 또는 계속 관리를 선택합니다. 추천 결과가 없으면 조건 변경·필수 옷 등록을 안내합니다. 미로그인은 가입 화면으로 이동하며 서버도 개인 API를 거절합니다. 네트워크·DB·메일·AI 키 오류를 별도로 안내합니다. 오프라인에서는 자료가 저장됐다고 표시하지 않습니다.

## 이미지와 접근성

참고 사진에는 샘플 설명을 유지하고 개인 사진은 서버 소유권 확인을 거쳐 표시합니다. 체형 버튼에 명확한 접근성 이름·선택 상태를 지정합니다. 키보드 포커스, 상태 메시지, 입력 라벨을 제공합니다. 브라우저 카메라/사진 선택의 실제 메뉴는 실기기에서 최종 확인해야 합니다.
