# 기획서 — Fashion Balance AI V2.1

## 목적과 대상

이미 가진 옷을 사진과 간단한 선택으로 등록하고, 계절·스타일·예산·기준 옷에 맞춰 코디를 고릅니다. PC에서 자세히 관리하고 휴대폰에서는 촬영·조회·추천을 간편하게 이용하려는 개인을 대상으로 합니다.

핵심 가치는 보유품의 추가 구매비용을 0원으로 계산하고 부족한 상품만 쇼핑 후보로 구분하는 것입니다. 의류뿐 아니라 모자·스카프·가방·벨트·시계·주얼리도 고려합니다.

## 구성과 범위

- 화면: React, 기존 아이보리·베이지·세이지 디자인과 사계절 참고 사진 유지.
- 업무 처리: Python/FastAPI에서 인증·사용자별 권한·추천·사진 분석·MySQL 접근.
- 데이터: MySQL 8, 비공개 사진 파일, 공용 카탈로그/샘플과 개인 옷 구분.
- 가입: QR로 가입 화면 접근 → 닉네임·이메일 → 인증 링크 → 자동 로그인 → 메인.
- 모바일: 반응형 화면·사진 선택/촬영·홈 화면 아이콘·설치/접속 안내.
- 기록: 추천 결과 저장과 최근 30회 이력 조회. 코디 채택은 기존처럼 화면 내 선택 상태.

## 현 단계에서 제공하지 않는 것

실제 결제·가격 비교·재고/배송·쇼핑몰 주문은 구현하지 않았습니다. 실시간 유행 데이터 자동 수집과 별도의 ML 모델 학습도 없습니다. 규칙 기반 코디 점수는 객관적인 외모 평가나 실제 유행 통계가 아닙니다. 체형/얼굴 분석은 사진에서 보이는 실루엣의 추정이며 치수·건강 진단을 하지 않습니다.

## 운영과 사업 가설

우선 개인용 또는 소규모 사용자 검증으로 진행합니다. 향후 구독·코디 상담·제휴 링크 모델을 검토할 수 있으나 매출·전환율·유료 의향은 아직 검증하지 않았습니다. 별도의 판매 가격이나 예상 매출을 확정하지 않습니다.
비용 항목은 서버·MySQL·사진 저장/백업·도메인·인증 메일·선택적 AI 호출입니다. 실제 제공업체 계약과 사용량을 확인해 견적을 작성해야 합니다.

## 완료 조건과 남은 검증

소스·문서·자동 테스트와 모의 API 기반 화면 검증은 수행합니다. 사용자 환경의 실제 MySQL·이메일·외부 AI·iPhone/Android·외부 HTTPS 접속은 인수검사 후에만 실사용 검증 완료로 표시합니다.
