## V2.0 · React + Python · 2026-10-22

- V1.9 Express API를 Python/FastAPI로 이식. 주요 인증·추천·이미지·MySQL 로직을 Python 파일로 분리.
- 화면을 React 상태·이벤트 기반으로 전환. 기존 레이아웃은 로컬 템플릿으로 보존하고 HTML 문자열로 사용자 데이터를 삽입하지 않음.
- 기존 코디 계산·가격 0원·기준 옷/색상·사계절 두 스타일·액세서리·체형 선택·AI/기기 내 색상 추정·쇼핑 링크 보존.
- PC·휴대폰 공통 지침 추가. 입력 크기·메뉴·사진 선택/촬영·좁은 화면 보강.
- 개인 사진·데이터 소유권 보호와 V1.9 DB 구조 유지. V1.9 사용자의 DB는 추가 변경 없음.
- 저장 완료 팝업과 메인 복귀/계속 관리 추가.
- 전환 전 전체 소스는 V1.9_ORIGINAL_BACKUP.zip으로 보존.
